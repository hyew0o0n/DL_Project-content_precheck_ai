# W6 v3 모델 오류 분석

## 목적

W5에서 채택한 v3(KcELECTRA + class weight) 모델이 validation 데이터에서
어떤 유형의 문장을 잘못 판단하는지 확인하기 위해 오류 사례 30개를 분석했다.

W6에서 결정한 `review_threshold = 0.4`를 기준으로
미탐(FN) 15개와 오탐(FP) 15개를 추출했다.

공식 test set은 사용하지 않았다.

## 분석 설정

- 모델: v3 KcELECTRA + class weight
- 데이터: K-MHaS validation
- review threshold: 0.4
- 미탐(FN): 실제 라벨이 있지만 해당 라벨 probability < 0.4
- 오탐(FP): 실제 라벨이 없지만 해당 라벨 probability >= 0.4
- 분석 사례: 미탐 15개 + 오탐 15개 = 총 30개
- 상세 원문: `results/b_error_candidates.md`

## 오류 유형 기준

이번 분석에서는 오류 원인을 다음 5가지로 나누었다.

1. **라벨 애매·주석 불일치 가능성**
   - 실제 문장 의미와 데이터셋 라벨의 경계가 애매하거나,
     문장에 문제 표현이 있는데도 해당 라벨이 정답에 포함되지 않은 경우

2. **문맥·암시적 표현**
   - 직접적인 혐오 단어나 욕설 대신 비꼼, 조롱, 암시적 표현 등으로 의미가 전달되는 경우

3. **은어·변형 표기·오타**
   - 인터넷 은어, 축약어, 비표준 표현, 오타 등으로 인해 표현 형태가 일반적인 학습 패턴과 다른 경우

4. **다중 라벨 혼동**
   - 한 문장에 여러 유형의 문제가 동시에 존재해 모델과 데이터셋의 라벨 선택이 서로 달라진 경우

5. **키워드 민감 과다탐지**
   - 특정 집단·정치·인종 관련 단어가 등장했다는 이유만으로 여러 라벨을 과도하게 예측한 경우

## 주요 발견

### 1. 데이터 라벨 자체가 애매한 사례가 많았다

오탐으로 추출된 사례 중에는 실제 문장을 보면
지역, 외모, 욕설, 종교, 연령 관련 비하 표현이 포함되어 있어
모델의 예측이 완전히 잘못되었다고 보기 어려운 경우가 있었다.

따라서 validation의 정답과 다르다는 이유만으로
모든 사례를 실제 서비스상의 오탐으로 해석하면 안 된다.

### 2. 명시적인 표현보다 암시적인 비하에 약했다

직접적인 욕설이나 집단명이 포함된 문장보다
조롱, 비꼼, 관용 표현처럼 문맥을 이해해야 하는 사례에서
미탐이 발생했다.

### 3. 은어와 비정형 표현이 미탐 원인이 되었다

인터넷 은어, 축약어, 오타, 변형 표기 등이 포함된 경우
일반적인 단어 형태와 달라 일부 라벨의 confidence가 매우 낮게 나타났다.

### 4. 다중 라벨 문장에서 정답과 모델의 관점이 달랐다

실제 한 문장에 욕설, 정치, 연령, 성별 등 여러 요소가 함께 포함되어도
데이터셋에는 일부 라벨만 기록된 사례가 있었다.

모델은 추가 라벨을 탐지해 FP로 계산되지만,
실제 서비스 관점에서는 검토가 필요한 표현일 수 있다.

### 5. 일부 문장은 특정 키워드에 지나치게 민감했다

인종명이나 정치 관련 단어가 짧게 등장한 문장에서
여러 라벨이 동시에 높은 확률로 활성화되는 사례가 확인되었다.

이는 실제 MVP에서 불필요한 경고가 많이 발생할 가능성이 있으므로
추후 실제 콘텐츠 기반 평가에서 다시 확인할 필요가 있다.

## 결론

v3 모델의 오류는 단순한 모델 성능 문제만으로 설명하기 어려웠다.

주요 원인은
`라벨 경계의 모호함`, `문맥 의존 표현`, `은어·변형 표기`,
`다중 라벨 문장`, `일부 키워드에 대한 과도한 반응`으로 정리할 수 있었다.

특히 데이터셋 기준의 FP 중 상당수는 실제 문장을 보면
위험 표현으로 볼 여지가 있어,
향후 실제 서비스 평가에서는 데이터셋 정답뿐 아니라
사람 검토 결과와 함께 평가하는 것이 필요하다.

이번 분석 결과는 W10 최종 결과 분석과
향후 모델 개선 방향을 정할 때 참고 자료로 활용한다.

※ 본 분석은 K-MHaS validation에서 추출한 30개 사례에 대한 정성 분석이며,
전체 오류 분포를 대표한다고 단정하지 않는다.
