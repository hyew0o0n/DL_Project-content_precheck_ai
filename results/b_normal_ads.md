# W6 정상 광고 문구 세트 수집

## 목적

광고성 문구 자체를 과대·과장 광고로 잘못 탐지하는 오탐을 확인하기 위해
문제없는 실제 광고·홍보 문구를 업종별로 수집한다.

본 세트는 우선 `exaggeration` 규칙의 오탐 평가에 사용한다.
브랜드 자체 광고와 인플루언서 협찬 게시물은 표시 의무 조건이 다를 수 있으므로
`missing_disclosure` 평가는 별도 세트로 다룬다.

## 현재 수집

- 총 30개
- 저장 파일: `data/b_normal_ads.csv`
- 실제 공개 프로모션 문구의 짧은 문장을 수집
- 현재 10개는 모두 사람이 확인하여 `expected_exaggeration=0`으로 기록

## 수집 기준

포함:
- 정상적인 할인율 안내
- 쿠폰·적립·구매 혜택
- 시즌 프로모션
- 이벤트 안내
- 일반적인 제품·서비스 홍보

제외:
- 치료·효능을 단정하는 표현
- 근거 없는 100%·무조건·완벽 보장 표현
- 혐오·욕설·정치 표현
- 개인정보가 포함된 문구
- 정상 여부를 사람이 판단하기 어려운 문구
