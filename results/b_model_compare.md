## 채택 모델

- **v5: KcELECTRA + 제곱근 class weight + 5 epoch** (threshold 0.5) — 체크포인트 `checkpoints/v5/final`
- Validation macro F1: **0.8066** (v3 대비 +0.054, 논문 베이스라인 0.765 대비 +0.042)
- Validation micro F1: 0.8800 (v1 0.8839와 거의 같음, v3 0.8540보다 높음)
- race F1: v1 0.00 → v3 0.34 → **v5 0.50**

### 해석

- macro F1이 낮았던 원인은 race 하나였음 (v1에서 race를 뺀 8개 라벨 평균은 약 0.85)
- 개선의 대부분(+0.04)은 class weight를 **제곱근으로 약하게** 준 효과. 가중치는 "넣느냐"보다 "얼마나"가 중요
- epoch은 5에서 충분 (8 epoch도 같은 수준)
- seed 3개 모두 0.80 이상 → 우연이 아님
- 라벨별 임계값 튜닝 효과는 작음 → threshold 0.5 유지 (`predict.py` 수정 불필요, `CKPT_DIR`만 v5로)
- v7(0.8071)과 v5_s123(0.8074)은 v5와의 차이가 seed 편차(±0.004)보다 작아 사실상 같은 성능 → 검증된 설정이고 더 짧은 **v5(seed 42)** 채택

- race는 val 24건뿐이라 1~2건에 F1이 크게 흔들림. 여전히 가장 약한 라벨 (v5 precision 0.44 / recall 0.58)
